HomeLink Wiki & System Guide

Homelab Architecture Overview

HomeLink v2.6 is designed for high-performance self-hosted environments. It runs inside lightweight container environments (such as Ubuntu VMs on TrueNAS SCALE/CORE), providing instant status checks, customizable dashboards, and zero external telemetry.

Role-Scoped Profiles & Wallpapers

HomeLink supports multiple user profiles alongside the Master Admin account. Each profile maintains its own isolated tile layout, custom category tabs, and wallpaper settings.

Live Health Pings & API Stats

HomeLink performs background health checks on your homelab services based on your configured ping interval (default: 60 seconds).

Backup, Migration & Heimdall Import

Your complete configuration (including profiles, tile layouts, custom backgrounds, and passwords) can be exported or imported at any time via Settings.
